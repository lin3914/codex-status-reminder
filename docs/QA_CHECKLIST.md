# 发布前实机验收

记录具体版本、build、Electron、Codex、macOS 和处理器。自动化通过与人工通过分开填写；未测试不能默认通过。

## 干净环境

- [ ] 不含 Codex、不含个人数据的 runner 上 npm ci / npm test / audit / build / check:release 实际通过。
- [ ] 依赖无未处理的高风险漏洞；Electron 在发布当日受支持且补丁已评估。
- [ ] 完整许可和权利审阅通过，没有私有图片、会话或账号资料。

## 安装与系统

- [ ] 从真实浏览器下载、保留隔离、无需安全绕过即可正常拖拽安装与打开。
- [ ] 正确 Logo、独立稳定 Bundle ID、一个菜单栏宿主，无运行中 Dock 图标。
- [ ] 左键开／关完整面板，右键配置菜单，悬停不弹。
- [ ] 正常退出、重复打开、3 次重启均稳定；主动退出不被恢复。
- [ ] 登录项开／关生效；登录后静默；异常重启有限，不能循环崩溃。
- [ ] 不写系统私有 Control Center／TCC／Dock 配置，不影响其他应用。

## 额度与任务

- [ ] 自动发现 Codex 标准和不同位置；连续失败才出现手动入口。
- [ ] 官方用量／兼容回退／网络失败／无周额度账户表现合理，缺失不显示为 0%。
- [ ] 额度剩余、周期剩余、重置时间与同一时刻 Codex 数据核对。
- [ ] 默认健康 12 小时／告警 24 小时，联动两倍与自定义边界一致；正常上限 0 小时时告警为 6 小时，缺值不告警。
- [ ] 正在运行、停止未读、停止已读分类正确；明确中止移出进行中。
- [ ] 未读状态单独失败时，停止任务显示待同步、待查看数量为“–”；恢复后与真实 Codex 回执核对，不能把未知当成已查看。
- [ ] 数量、排序、状态颜色、滚动、长标题和中英文正确。
- [ ] 点击会话正常跳转；应用没有改写 Codex 的已读数据。

## 桌面与提醒

- [ ] 桌面开关、悬停、点击、拖动跟随、位置保存、透明背景、双环无白线。
- [ ] 多空间与全屏约束、多显示器接入／拔出、睡眠／唤醒恢复。
- [ ] Codex 前台不打扰，后台新完成时出现提醒；历史未读不批量轰炸。
- [ ] 新提醒最前、分组展开、每条手动关闭位置正确、关闭不标已读。
- [ ] 从 Codex 查看后自动移除；读状态失败不清空全部提醒。
- [ ] 点击提醒即撤下并请求打开会话；跳转失败不写已读，任务面板仍能再次打开。
- [ ] 独立 ChatGPT 前台不抑制 Codex 完成提醒；只有已发现的 Codex 身份才抑制。
- [ ] 关闭期间完成但未同步的任务不因重新开启被补推；首次刷新和稍后发现的历史记录均不轰炸。
- [ ] 通知渲染崩溃、加载失败／超时有限恢复；持续失败不循环重启；手动关闭、退出或禁用时不复活。
- [ ] 重启暂缺索引／未读时恢复已缓存标题摘要；写入失败不阻断当前提醒，恢复可写后重试。
- [ ] 多于三条提醒可滚动且刷新不复位；600 条合成完成的容量和去重检查通过。实机仅用测试拥有的窗口，不能向真实 Codex 注入任务。
