# Token 速率：实现规格与验收

## 展示与计算

1.9.17（78）的整体速率在「Token 用量与速率」区的第三格。会话速率放在标题行、紧靠状态标签左侧；下一行显示累计用量，保留三行最新进展。当前行高98px，三张卡片视窗306px，面板高度上限545px。保留状态色、滚动和点击打开会话，见[用量与验收](TOKEN_USAGE.md)。

1.9.17（75）起，进行中为橙色（`#d4ac84`）、待查看为灰绿色（`#95b7a3`）、已处理为灰色（`#a5b1b9`）；行内速率与对应标签同色，整体速率与进行中同色。速率、状态标签和进展正文共享10.5px字号；标题为12px／650字重。下方保留历史构建的验收记录。

- 进行中：每次收到有效用量，以该次上报时刻所选范围内的已上报输出Token除以该范围秒数，直接显示“X tok/s”。包含思考Token，输入与缓存Token不计入。两次上报之间保持该值，不随旧样本逐条到期而下降；新用量到达后重新计算。卡片、悬停和无障碍文案不区分“实时”与“沿用”，不展示采样范围或近似符号。
- 沿用仅限同一会话当前轮次已有的有效记录。新轮次、数据损坏／计数回退或从未取得有效值时不借用其他任务数据；当前没有可信参考值的运行行显示“待上报”。新任务不沿用上一轮已结束任务的平均值。
- 整体：只汇总本应用已同步的顶层本地进行中会话，直接显示“X tok/s”，悬停给出有速率的会话数量。无进行中显示0，所有活动会话均无可信参考时显示“—”；不把未上报会话填成0，不扩大到云端或子任务。待查看和已处理的平均速率不计入整体。
- 已停止：显示最近一轮完整运行的“平均 X tok/s”＝该轮输出Token÷完整运行秒数，含思考、工具和等待，不含用户轮次之间的空闲。
- 暂停、中止与完成均立即退出实时汇总。重复用量记录不重复累计，计数回退、缺失完整开始或结束、未知耗时均显示“样本不足”，不根据文本长度估算Token。

常规设置增加`tokenSpeedWindowSeconds`，只接受30／60／300，缺失或非法值归30；现有配置不需要迁移或重置。选择通过原设置IPC保存，并立即刷新整体与会话速率；已结束平均值保持不变。

## 数据与资源

独立实现本地只读采样，Token Monitor只用于核对用户需要和已有指标含义，不引入该程序的云连接或恢复会话策略。复用现有Codex目录发现、SQLite只读连接、worker内JSONL增量读取和文件监听。新增模块同时打入ASAR和外置worker资源。

旧记录缺少本轮开始时，对近期十条及活动会话先进行一次最多8MiB的尾部回看。仍不足时，从快照末尾反向按256KiB分段读取元数据，直到找到最近一轮开始和上一轮累计输出基线；每次worker刷新共用8MiB预算，在后续刷新中继续，完成后不重复扫描。平均值＝（该轮最终累计输出−该轮之前累计输出）÷该轮耗时；首轮没有前序报告时以首个报告的本次输出还原基线。缺失边界、计数回退和记录损坏仍保留未知；补齐过程中显示“—”。增量读取继续正常接收新报告，新轮次和文件更换会取消旧的补齐任务。

反向补齐只保留计数、轮次边界和最多64KiB的残行，跳过更大的工具输出行，不保存会话全文或凭据。实时采样沿用最多4096个近5分钟数值样本；平均值恢复不伪造缺失的实时采样。切换范围直接使用缓存；实时范围覆盖不足或样本数溢出时保留未知。

1.9.17（69）起，有进行中任务时增加10秒元数据兜底检查，隐藏面板也保留增量采样缓存。检查只对已知活动会话执行stat，未变化时不查询SQLite、不读取JSONL、未读状态或认证文件，也不更新渲染器；发现变化后复用正常增量同步。正常文件事件刷新会推迟这次兜底，避免重复读取。无进行中任务、睡眠、锁屏或退出时停止新增检查。1.9.17（74）取消仅为速率变旧而切换文案的定时唤醒，只在覆盖补足或未来时间记录需要进入统计时唤醒一次。已有值直接从同一份有上限的数值样本重建，没有新增常驻进程、网络请求或持久化缓存。后台检查的原始验收见[10秒准实时刷新](TOKEN_SPEED_REFRESH.md)。

1.9.17（76）根据任务面板显隐切换兜底频次：可见约3秒，隐藏维持约10秒，两种状态共用一个定时器。打开仍直接展示缓存，不等待磁盘；文件事件仍优先，只有活动文件确有变化才进入原有增量同步。30秒／1分钟／5分钟仍是计算范围，已结束会话的平均口径也不变。

1.9.16（68）交付时，按用户要求替换安装到本机“应用程序”，保留旧应用与完整配置备份，验证后恢复原有桌面组件设置，统计窗口设为默认30秒，再普通重启并关闭本地调试端口。随后获准将这份最终版本公开到GitHub，ZIP保留原始字节，DMG内应用逐文件一致，详见[该版发布说明](releases/v1.9.16.md)。保留历史1.9.15资产，不修改Token Monitor。

用户确认安全补丁升级后，将Electron由43.7.9更新到同一大版本的43.8.7，同时更新下载工具的兼容补丁依赖undici至7.30.2。证书校验通告从43.8.1起修复，见[官方安全通告](https://github.com/advisories/GHSA-jr5w-w6x2-84p9)；当前补丁见[Electron 43.8.7](https://releases.electronjs.org/release/v43.8.7)。没有迁移应用框架或修改系统权限。
