# CodeX状态提醒：首次公开候选

## 1.9.15（66）：后台提醒与窗口遮挡修复

提供 Apple Silicon 公开试用安装包，使用 ad-hoc 签名，尚未完成 Developer ID 签名和 Apple 公证；首次打开可能被 macOS 阻止。下载入口、安装方法和验证范围见[本版说明](releases/v1.9.15.md)。

- 仅在确认 Codex 不在前台时显示任务完成提醒；打开或切回 Codex 后，全部提醒一起撤下。
- 离开 Codex 后不补推这些旧提醒，之后新完成的后台任务仍可正常提醒。撤下提醒不改写 Codex 未读状态；关闭按钮仍只移除单条。
- 改用标准浮动窗口层级，不再反复抬高已有提醒，避免挡住其他应用后来出现的通知。
- 使用只读、事件驱动的 macOS 公共前台应用通知，不增加辅助功能、屏幕录制或自动化权限要求。
- 打包通知验证 17 项、界面验证 5 组通过；在实际安装的本版本上另完成 9 项检查，包括四条提醒切回真实 Codex 后全部撤下，以及另一应用的新通知跨过 62 秒后台刷新后仍处于上方。

公开 DMG 和 ZIP 保持本轮已验证文件的原始字节，校验值记录在[版本清单](releases/v1.9.15.json)。没有重新打包，也没有把本机配置、提醒缓存或回退备份放入公开资产。版本标签为 `v1.9.15`；[GitHub 下载页](https://github.com/lin3914/codex-status-reminder/releases/tag/v1.9.15)。

本轮仅在 Apple Silicon、macOS 27.0 进行了上述实机验收；不等于所有 Mac、所有 Codex 版本或所有第三方 IM 通知都已验证。Intel 包、Developer ID 公证正式包和自动更新器不在本次发布范围。

## 历史源码基线：1.9.14 及之前

沿用现有任务、额度、菜单栏和桌面组件功能，整理独立源码、开发文档与固定样本回归。增加渲染窗口 IPC／导航限制、构建 CSP、第三方许可保留和签名草稿发行流程。

功能基线为 1.9.11（62），以下历史记录截至 1.9.14（65）。维护者已确认代码与图标公开权利，并选择 Apache-2.0。固定样本与打包界面验证仍不能替代 Developer ID 签名、公证或跨设备验证。

Electron 同一大版本补丁更新为 43.7.9；修正自定义健康上限为 0 小时时仍显示默认 12 小时的问题，计算规则不变。修正展开通知高度少算内边距等固定区域、导致第三条底部被裁切的问题。历史本地迁移安装器默认禁用，正常安装使用 Finder 拖拽；正式发行工作流使用同一个临时钥匙串保存签名和公证凭据。

本应用不是 OpenAI 官方产品。用量与任务兼容性受 Codex 版本／登录方式影响；任务与未读仅按本机可读取范围展示。不会修改 Codex 数据。

移除菜单栏排障中“还原控制中心”的建议，避免为本应用故障重置其他应用配置。文档补清 0 小时联动特例、提醒点击即撤下与 Codex 已读同步的区别。

修复后台完成提醒漏发：旧代码依赖 lsappinfo 的输出字段名，当前 macOS 返回的字段与正则不符，导致前台状态长期未知；15 秒后又把未判明的完成记录消费掉。改为打包 helper 通过 NSWorkspace 公共接口异步读取前台，未知状态保留有界、持久的待判断队列。已读数据暂时不可用时不清除现有提醒；已知未读集合延迟更新时保留 10 分钟对齐时间。首次启动不轰炸历史任务、前台不打扰、手动关闭和同一轮去重规则不变。

增加 `npm run test:notifications`：使用模拟任务、临时配置和打包后的代码／真实窗口，验证完成事件到卡片显示、关闭和已读撤下的链路，不访问 Codex 数据，不修改系统通知权限。

公开构建不再依赖内部 npm 镜像。修补构建期传递依赖 xmldom、brace-expansion 和 undici，并保留同一 Electron 43.7.9；修正旧 Swift 编译器对异步闭包中弱引用的并发检查问题，以及签名工作流的上下文位置。上述构建适配不改变应用的任务、额度或通知行为。

1.9.14 完成提醒独立验证：修复独立 ChatGPT 身份误判、首次同步漏掉启动后完成、稍后发现的历史任务误推、关闭期间未同步消息补推、明确未读记录被过早消费、队列裁剪后的重复推送，以及未读读取失败时误显示“已处理”。旧兼容未读格式改为最新字段优先，空集合不再被旧数据覆盖。

提醒状态升至 v4，兼容旧队列，保存最多 100 条待查看提醒的标题与摘要；暂缺索引时可恢复已缓存内容。通知窗口崩溃、加载失败与 10 秒超时只有限重建窗口，60 秒内最多 2 次自动重试，持续失败尝试原生回退。状态写入失败保留当前提醒并在正常同步时重试，不新增高频轮询。无内容变化时不重复写状态或重建通知 DOM，展开列表的滚动位置不因刷新丢失。

新增独立契约、窗口故障注入、600 条批量与 2,000 次确定性状态转换、未读刷新到 UI 以及真实打包窗口回归。测试使用虚构任务和临时配置，不写 Codex 数据，不修改系统权限。正式二进制仍须 Developer ID、公证、保留下载隔离和跨设备／长期运行验收，不因源码测试通过而宣称已完成发行。
