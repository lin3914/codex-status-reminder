# 图标来源与当前样式

这是本项目多轮生成与程序绘制后形成的独立应用图标，不使用 OpenAI 官方标记或 Flux Island 吉祥物。权利状态仍需项目维护者确认；生成过程本身不是权利证明。

当前生产稿为深色圆角底、单个开放色环、青绿色到黄色／橙色的平滑过渡。中心大四芒星和开口处小四芒星同向倾斜；菜单栏使用对应的单色模板及 Retina 2x 图像，不把应用的方形底框带进菜单栏。

`generate-icon-assets.mjs` 是当前生产资源生成脚本，PNG、ICNS 与 Tray 模板均来自同一几何定义。桌面额度组件采用时间／额度双环，不等于 Logo 必须画两个完整同心环。

本轮开源整理没有改变这些图像字节。目录中的历史中间稿只作为生成输入或开发资料保留，不作为另一个应用 Logo 注册。
